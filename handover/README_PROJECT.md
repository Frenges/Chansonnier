# Chansonnier — Présentation rapide

**But**  
Application web statique (SvelteKit) affichant un recueil de chansons. PWA avec service worker pour accès hors‑ligne.

**Stack technique (exemples)**  
- **Frontend** : Svelte / SvelteKit  
- **Bundler** : Vite  
- **Hébergement** : GitHub Pages (build statique)  
- **Service worker** : `static/service-worker.js` (gestion manuelle du cache)

**Repère fonctionnel recommandé**  
- Branche stable : `stable/functional-YYYY-MM-DD`  
- Tag annoté : `v1.0.0-functional`

Voir `ENV_VERSIONS.md` pour les versions détectées automatiquement sur cette machine.
